# Лабораторная работа 1. Файлы и каталоги

| Файл        | Что делает                                              |
|-------------|---------------------------------------------------------|
| `create.c`  | создаёт каталог (только вызовы из раздела 1.2)          |
| `remove.c`  | рекурсивно удаляет каталог (средний вариант)            |
| `create.sh` | создаёт тот же каталог командами оболочки               |

## Запуск

```sh
make                 # собрать create и remove
./create             # создать каталог программой
ls -lR a             # показать результат (или: tree a)
./remove a           # удалить каталог программой
./create.sh          # создать каталог скриптом
ls -lR a
```

## Как переделать под задание преподавателя

Меняется только тело `main` в `create.c` и содержимое `create.sh`.
Сначала создаются каталоги, потом файлы, в конце ссылки
(жёсткая ссылка требует, чтобы исходный файл уже существовал).

| В задании                    | `create.c`                               | `create.sh`                          |
|------------------------------|------------------------------------------|--------------------------------------|
| каталог `a/b`                | `make_dir("a/b");`                       | `mkdir a/b`                          |
| `x.txt` (пустой)             | `make_empty("a/x.txt");`                 | `touch a/x.txt`                      |
| `x.txt` ("строка")           | `make_text("a/x.txt", "строка\n");`      | `echo строка > a/x.txt`              |
| `x.bin` (N байт, случайный)  | `make_random("a/x.bin", N);`             | `head -c N /dev/urandom > a/x.bin`   |
| `x.bin` (N байт, нули)       | `make_zero("a/x.bin", N);`               | `truncate -s N a/x.bin`              |
| `d` — ссылка на `c`          | `make_symlink("c", "a/d");`              | `ln -s c a/d`                        |
| `f` — жёсткая ссылка на `b/x`| `make_hardlink("a/b/x", "a/e/f");`       | `ln a/b/x a/e/f`                     |

Про пути в ссылках:

- **символьная**: цель пишется относительно каталога, где лежит сама ссылка
  (`a/d -> c` означает `a/c`);
- **жёсткая**: оба пути пишутся относительно каталога, из которого запущена
  программа или команда.

Проверка жёсткой ссылки: в `ls -li` у обоих имён одинаковый номер inode,
а счётчик ссылок равен 2.

## Сложный вариант: монтирование флешки

```sh
lsblk                          # найти флешку, например /dev/sdb1
sudo mkdir -p /mnt/flash       # каталог, заданный преподавателем
sudo mount /dev/sdb1 /mnt/flash
ls /mnt/flash                  # проверить
sudo umount /mnt/flash         # размонтировать
```
